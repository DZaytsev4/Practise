{% if algorithm == "bubble_sort" %} Сортировка пузырьком — это простой алгоритм сортировки, который многократно проходит по списку, сравнивает соседние элементы и меняет их местами, если они идут в неправильном порядке. Процесс повторяется, пока весь список не будет отсортирован. {% elif algorithm == "insertion_sort" %} Сортировка вставками строит отсортированный массив по одному элементу за раз. Алгоритм берет следующий элемент из неотсортированной части массива и вставляет его в нужную позицию в отсортированной части. {% elif algorithm == "merge_sort" %} Сортировка слиянием — это алгоритм "разделяй и властвуй". Массив делится на две части, каждая из которых сортируется рекурсивно, а затем части сливаются обратно в отсортированный массив. {% elif algorithm == "quick_sort" %} Быстрая сортировка — это эффективный алгоритм, который выбирает опорный элемент (пивот) и разделяет массив на две части: одну с элементами меньше опорного, а другую с большими. Затем каждая часть сортируется отдельно. {% endif %}

Пример кода:


                    {% if algorithm == "bubble_sort" %}
                        def bubble_sort(arr):
                            for i in range(len(arr)):
                                for j in range(0, len(arr)-i-1):
                                    if arr[j] > arr[j+1]:
                                        arr[j], arr[j+1] = arr[j+1], arr[j]
                    {% elif algorithm == "insertion_sort" %}
                        def insertion_sort(arr):
                            for i in range(1, len(arr)):
                                key = arr[i]
                                j = i - 1
                                while j >= 0 and key < arr[j]:
                                    arr[j + 1] = arr[j]
                                    j -= 1
                                arr[j + 1] = key
                    {% elif algorithm == "merge_sort" %}
                        def merge_sort(arr):
                            if len(arr) > 1:
                                mid = len(arr) // 2
                                left = arr[:mid]
                                right = arr[mid:]
                                merge_sort(left)
                                merge_sort(right)
                                i = j = k = 0
                                while i < len(left) and j < len(right):
                                    if left[i] < right[j]:
                                        arr[k] = left[i]
                                        i += 1
                                    else:
                                        arr[k] = right[j]
                                        j += 1
                                    k += 1
                                while i < len(left):
                                    arr[k] = left[i]
                                    i += 1
                                    k += 1
                                while j < len(right):
                                    arr[k] = right[j]
                                    j += 1
                                    k += 1
                    {% elif algorithm == "quick_sort" %}
                        def quick_sort(arr):
                            if len(arr) <= 1:
                                return arr
                            pivot = arr[len(arr) // 2]
                            left = [x for x in arr if x < pivot]
                            middle = [x for x in arr if x == pivot]
                            right = [x for x in arr if x > pivot]
                            return quick_sort(left) + middle + quick_sort(right)
                    {% endif %}

{% elif algorithm == "stack" %}

Алгоритм Стек

Стек — это структура данных, которая работает по принципу "Последним пришел — первым ушел" (LIFO). Это означает, что последний добавленный элемент будет первым, который мы уберем. Стек поддерживает операции добавления элемента (push) и удаления элемента (pop).

Пример кода:


                    stack = []
                    def push(value):
                        stack.append(value)

                    def pop():
                        if stack:
                            return stack.pop()
                        return None
{% elif algorithm == "queue" %}

Алгоритм Очередь

Очередь — это структура данных, работающая по принципу "Первым пришел — первым ушел" (FIFO). Это означает, что первый добавленный элемент будет первым удален. Очередь поддерживает операции добавления элемента (enqueue) и удаления элемента (dequeue).

Пример кода:


                    queue = []
                    def enqueue(value):
                        queue.append(value)

                    def dequeue():
                        if queue:
                            return queue.pop(0)
                        return None
{% elif algorithm == "linear_table" %}

Линейная таблица на основе массива

Линейная таблица — это структура данных, которая хранит элементы в виде массива. Элементы добавляются и удаляются последовательно.

Пример кода:


                    linear_table = []
                    def insert(value):
                        linear_table.append(value)

                    def delete(value):
                        if value in linear_table:
                            linear_table.remove(value)
{% elif algorithm == "tree_table" %}

Таблица на основе дерева

Таблица на основе дерева использует структуру данных "дерево" для хранения элементов. Каждый элемент имеет ключ и значение, и элементы упорядочены по ключу.

Пример кода:


                    tree_table = {}
                    def insert(key, value):
                        tree_table[key] = value

                    def delete(key):
                        if key in tree_table:
                            del tree_table[key]
{% elif algorithm == "hash_table" %}

Хеш-таблица

Хеш-таблица — это структура данных, которая использует хеш-функцию для быстрого доступа к элементам по ключу. Элементы хранятся в виде пар ключ-значение.

Пример кода:


                    hash_table = {}
                    def insert(key, value):
                        hash_table[key] = value

                    def delete(key):
                        if key in hash_table:
                            del hash_table[key]
{% elif algorithm == "sorted_table" %}

Таблица с сортировкой на основе массива

Таблица с сортировкой хранит элементы в отсортированном порядке. При добавлении нового элемента таблица автоматически сортируется.

Пример кода:


                    sorted_table = []
                    def insert(value):
                        sorted_table.append(value)
                        sorted_table.sort()

                    def delete(value):
                        if value in sorted_table:
                            sorted_table.remove(value)
